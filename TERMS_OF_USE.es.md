# Términos de uso — Pulsaria Beta

Versión: 1.0 · 12 de septiembre de 2026

## Alcance

Estos términos regulan el uso del sitio, repositorio, documentación, issues,
releases e instaladores oficiales de Pulsaria. El uso del programa también
está sujeto al EULA.

Pulsaria es un beta gratuito. No requiere una cuenta ni cobra por suscripción
en esta versión. Cualquier versión futura con pagos tendrá términos
comerciales adicionales antes de cobrar.

## Uso aceptable

Puedes descargar y utilizar un release oficial para evaluar Pulsaria,
procesar contenido que tengas derecho a utilizar y reportar problemas de
forma responsable.

No debes utilizar el repositorio, los instaladores o la infraestructura de
GitHub para:

- distribuir material ilegal, privado o protegido sin autorización;
- publicar claves, cookies, datos personales o material de terceros;
- evadir controles de una plataforma;
- atacar, saturar o interferir con GitHub, Pulsaria o el equipo de otra
  persona;
- suplantar a Pulsaria o a su titular;
- crear una distribución no oficial que parezca oficial.

## GitHub e incidencias

GitHub es un servicio de terceros sujeto a sus propios términos. Las issues,
discussions y pull requests son espacios públicos salvo que GitHub ofrezca un
canal privado. No incluyas transcripciones, vídeos, bases de datos, cookies,
tokens, credenciales ni información personal.

Para vulnerabilidades utiliza el procedimiento de SECURITY.md. Para
reclamaciones de copyright utiliza COPYRIGHT_AND_TAKEDOWN.es.md.

## Marca y plataformas

“Pulsaria” es la identidad del producto. TikTok, ByteDance, YouTube y Google
son marcas de sus respectivos titulares. Pulsaria no está afiliada,
patrocinada ni respaldada por ellos.

La compatibilidad con una plataforma no implica autorización de esa
plataforma. Debes cumplir sus términos y políticas.

## Cambios y disponibilidad

El beta puede cambiar, suspenderse o retirarse sin aviso. Podemos corregir
errores, cambiar endpoints, retirar funciones o publicar nuevas condiciones
para versiones futuras.
