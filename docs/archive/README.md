# Archivo documental histórico

`PROJECT_TRUTH.md` es la única autoridad técnica actual. Los documentos de
esta carpeta y los documentos de auditoría/especificación heredados conservan
trazabilidad histórica; no deben usarse para decidir el estado actual sin
compararlos con el código y los gates reproducidos.

Se consideran históricos, entre otros, los planes y reportes con nombres
`PULSAR_*`, `MVP.md`, `AUDITORIA_AAA.md`, `kiloonix.md`, fichas de estado,
auditorías de sesiones, diagramas y briefs anteriores. Los documentos legales (`LICENSE`, EULA,
privacidad, política de contenido y avisos de terceros) permanecen fuera de
este archivo porque regulan funciones legales específicas y no compiten con la
verdad técnica.

Cuando se retire o reemplace un documento histórico, conservar su nombre,
fecha y referencia en el commit que lo archive. No crear otro documento
"maestro", "definitivo" o "source of truth".
