# Archivo histórico de auditorías

Los documentos de esta carpeta son reportes históricos de desarrollo y no
forman parte de la documentación contractual ni del release público de
Pulsaria. Algunas auditorías describen decisiones o integraciones que fueron
retiradas posteriormente, incluida una integración cloud experimental.

La documentación vigente y jurídicamente relevante para el beta está en la
raíz del repositorio (`LICENSE`, `EULA.*`, `PRIVACY.*`,
`CONTENT_POLICY.*`, `COPYRIGHT_AND_TAKEDOWN.*`, `SECURITY.md` y
`THIRD_PARTY_NOTICES.md`).
